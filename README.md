# Mémoire de M2 TNAH — sources LaTeX

Sources LaTeX du mémoire de master « Technologies numériques appliquées à l'histoire » (École nationale des chartes, 2026) :

*Dans quelle mesure les spécificités documentaires d'une bibliothèque patrimoniale spécialisée conditionnent-elles la possibilité d'automatiser la cotation Library of Congress, et quelles limites imposent-elles à cette automatisation ?*

Anaëlle Martinez, sous la direction de Lauryne Lemosquet.

## Structure

- `memoire.tex` : document maître (préambule, page de titre, pages liminaires, appel des fichiers enfants)
- `introduction.tex`, `partie1.tex`, `partie2.tex`, `partie3.tex`, `conclusion.tex`, `annexe.tex` : corps du mémoire
- `glossaire.tex` : entrées du glossaire et de la liste des acronymes
- `bibliographie.bib` : bibliographie (classée par mots-clés)
- `schema_pipeline_cascade.pdf` : schéma inséré dans la partie 2
